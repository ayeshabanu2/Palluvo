---

### 3. Files Remaining JavaScript & Technical Rationale

The following 2 root configuration files intentionally remain JavaScript:
1. **[`next.config.js`](next.config.js)**: Evaluated directly by the Node.js runtime during Next.js server bootstrap before TypeScript transpile hooks are loaded. Next.js natively uses `.js` for root runtime configuration.
2. **[`postcss.config.mjs`](postcss.config.mjs)**: Evaluated directly by the PostCSS runner / Tailwind CSS engine, which expects standard ES modules (`.mjs`).
