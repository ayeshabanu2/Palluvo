### [P2/P3] Keep the Complete Brand Tagline Visible Across Narrow Screens Without Ellipsis Truncation
**Affected File:** [`src/components/Header.js:133`](file:///c:/Users/muham/OneDrive/Desktop/Palluvo/src/components/Header.js#L133)

- **Reviewer Note:**
  - *“The narrow-screen brand tagline is only fixed below 380px. In src/components/Header.js:133, the xs: breakpoint restores 9.5px type with 0.18em tracking at 380px. The tagline text measures 190px in a 178px box, and the rendered header shows “EVERY DRAPE, A LITTLE MA…”; at 390px it still exceeds the box by 2px. Please keep the compact type/spacing until the complete line fits, or let it wrap, rather than truncating the brand copy.”*

- **Root Cause & Layout Analysis:**
  - In `src/components/Header.js:133`, the brand tagline previously contained:
    ```jsx
    <span className="text-[7px] xs:text-[9.5px] sm:text-[11px] tracking-[0.03em] xs:tracking-[0.18em] sm:tracking-[0.28em] uppercase text-[#665E57] font-sans block -mt-0.5 sm:-mt-1 font-semibold truncate">
      Every drape, a little magic.
    </span>
    ```
  - At 380px (`--breakpoint-xs: 380px`), `xs:` activated prematurely:
    - Text: `text-[9.5px] uppercase tracking-[0.18em]` across 28 characters = **190.5px** wide.
    - Available container width at 380px: **178px–186px** (accounting for viewport padding, mobile menu button, action icons, and flex gaps). Text overflowed the container.
    - At 390px: Available container width is **188px–196px**, still leaving text overflowing.
    - The `truncate` class (`overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`) forced an ellipsis mid-word: `“EVERY DRAPE, A LITTLE MA…”`.

- **Resolution:**
  1. **Removed `truncate` in Favor of `whitespace-normal sm:whitespace-nowrap leading-tight`:**
     - The brand copy is **never truncated with an ellipsis**.
     - If the viewport or zoom ever constrains the line, words wrap naturally rather than clipping brand copy.
  2. **Preserved Compact Type & Spacing Throughout Mobile:**
     - Removed the premature `xs:` step-up.
     - Kept compact type/spacing (`text-[7.5px] tracking-[0.04em]`) across mobile viewports (320px through 639px), where the rendered text width is **~132.5px to 143.5px**.
     - This provides **42.5px of clearance at 380px** (143.5px in 186px box) and **52.5px of clearance at 390px** (143.5px in 196px box).
  3. **Progressive Responsive Scaling:**
     - At `sm` (640px): `sm:text-[9px] sm:tracking-[0.14em]` (213.9px text in 252px box = **38.1px clearance**).
     - At `md` (768px+): `md:text-[11px] md:tracking-[0.28em]` (251.1px text in 374px box = **122.9px clearance**).
  4. **Updated Implementation in `src/components/Header.js:133`:**
     ```jsx
     <span className="text-[7.5px] sm:text-[9px] md:text-[11px] tracking-[0.04em] sm:tracking-[0.14em] md:tracking-[0.28em] uppercase text-[#665E57] font-sans block -mt-0.5 sm:-mt-1 font-semibold whitespace-normal sm:whitespace-nowrap leading-tight">
       Every drape, a little magic.
     </span>
     ```
